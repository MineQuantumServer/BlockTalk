# BlockTalk

Minecraft 1.21.1 + NeoForge 21.1.264 的纯客户端 TeamSpeak 3 语音 MOD，Java 21。
这是非官方客户端，不使用 TeamSpeak 官方标识，也不需要安装或启动官方客户端。
Minecraft 服务端无需安装本 MOD；语音直接通过用户指定的独立 TS 服务器传输。

**当前版本：0.1.0-alpha.1。已完成一次官方 TeamSpeak 客户端双向人工听音；首次发送的严重杂音重试后正常，原因仍待定位。**
Windows x86_64 上已完成游戏界面启动、Opus 1.6.1 原生加载、真实服务器认证与
频道切换，以及两个独立 BlockTalk 会话间的真实麦克风双向 UDP 收发和解码。
另已使用同一正式核心的独立联调入口，与用户安排的官方客户端完成双向听音。
这不等于全部游戏内场景或长期稳定性验收通过。详见 `docs/OFFICIAL_INTEROP.md`。

## 安装与首次连接

1. 安装 Minecraft **1.21.1**、Java **21** 和 NeoForge **21.1.264**。
2. 将 `blocktalk-0.1.0-alpha.1.jar` 放入该客户端实例的 `mods/`。无需另装音频库、
   协议库、TeamSpeak 软件或 Minecraft 服务端插件。
3. 在主菜单或暂停菜单点击左上角 **BlockTalk**；游戏内也可按 **K** 打开面板。
4. 打开连接与收藏，输入显示名、服务器地址、昵称及可选默认频道名称/ID。
   支持域名、IPv4、`host:port`、`[IPv6]:port`；端口范围 1–65535，默认 9987。
   未显式指定端口时查询 `_ts3._udp` SRV；不支持 TSDNS 或官方服务器短名称。
5. 保存收藏后连接，密码在单独输入界面临时输入，可留空，**不会持久化**。
6. 在音频设置选择设备、增益与音量，然后点保存。建议戴耳机。
7. 进入世界后，**按住 V 说话，松开停止**。连接成功、重连成功和进入新频道都
   不会自动开麦；中断后必须松开并重新按下。主菜单始终禁止发送语音。

默认不自动连接。V/K 使用 Minecraft 原生按键设置，可重绑定，包括鼠标键。
失焦、文字输入、切换频道、静音、拒听、断线和退出世界都会关闭发送门。
默认退出世界会断开 TS；可选择保留连接，但退出时依然停止发言。
普通界面 PTT 设置仅允许暂停菜单和无文字输入的主面板，聊天、密码和其他未知
MOD 界面仍禁用 PTT。HUD 的发送状态来自实际发送路径，未伪造延迟/丢包数值。

## 频道、用户与设备

- 左侧频道树支持鼠标滚轮，点击加入；`*` 表示需要频道密码。拒绝原因会显示在面板。
- 右侧显示当前频道用户及实际可得的 M（麦克风静音）、D（拒听）、L（本地静音）状态。
  选择用户可切换本地静音或设为 50%/150% 个人音量；高级音量值保存在设置文件。
- 拒听会同时禁止自己发言；恢复拒听不改变此前手动麦克风静音选择。
- 设备和收藏按钮依次切换条目。音频设置只在保存后应用，不会拖动滑块每帧写盘。
- 本地麦克风监听仅在断开 TS 时显式启动；使用已保存设备，关闭页面会停止。
  监听音频不会进入网络发送路径。先保存设备选择，再重新打开设置启动测试。
- 输入为 48 kHz 单声道；播放为 48 kHz 双声道。设备只支持 44.1 kHz 时使用线性重采样。
  选定设备消失或打开失败时禁用音频并保留界面；重新选择设备并保存可重试。

## 支持范围

首版针对 **TS3 协议、20 ms Opus Voice（单声道）和 Opus Music（双声道）**。
Music 发送会将单声道麦克风复制为双声道；接收保留远端立体声。旧 Speex/CELT
频道和其他帧时长不解码、不发送。FEC、VAD、自动增益、降噪、回声消除均未启用。
不包含距离语音、录音、文件传输、官方账号、权限管理或私聊；文字聊天暂未交付。
TS6 等其他服务端没有独立验收，不宣称兼容。

|---|---|

| 两个独立 BlockTalk 会话 | 真实麦克风、TS UDP 路由、双方解码与松键停止通过；非官方客户端验收 |

## 配置、身份与隐私

普通配置/收藏：`config/blocktalk/settings.json`，带 `schemaVersion`、校验、迁移、
损坏文件备份和原子写入。收藏没有密码字段。没有“记住密码”选项。

身份私钥：`config/blocktalk/identity/private.identity`，与普通配置分离，使用
Windows 所有者 ACL / POSIX 0600。**文件是私钥的明文存储，不是加密文件**；拥有
同一账户或管理员权限的人仍可能读取。备份身份文件等同于备份身份控制权，不应
随源码、截图或问题报告发送。身份损坏时保留文件并失败，不静默重建新 UID。
身份页面可查看 UID、提升安全等级、取消计算、确认重置和复制脱敏诊断。
重置会失去服务器上绑定旧 UID 的权限。安全等级计算使用后台单核、限 30 秒和
最高目标 24，不绕过服务器要求。

默认无遥测、无录音、无远程配置、无运行时下载可执行代码。诊断不含服务器地址、
用户昵称、私钥、密码或原始音频。不要把整个游戏日志或身份目录公开上传。

## 构建和开发联调

安装 JDK 21 并设置 `JAVA_HOME`，在仓库根目录运行：

```powershell
.\gradlew.bat clean test build
.\gradlew.bat nativeSmoke :core:nativeTest
.\gradlew.bat runClient
```

Linux 构建使用 `bash gradlew clean test build`。编译不需要 C/C++ 工具链；已审查
的 Windows Opus DLL 随源码一起保存。只有显式重建 DLL 才使用 `tools/rebuild_opus.py`。
发行 JAR 位于 `build/libs/blocktalk-0.1.0-alpha.1.jar`，必要依赖通过 Jar-in-Jar 内嵌。

独立真实协议入口复用正式会话/音频实现，可不启动 Minecraft：

```powershell
$env:BLOCKTALK_TS_ADDRESS = 'your-host:9987'
$env:BLOCKTALK_TS_NICK = 'BlockTalk-Integration'
# 如需要密码，请在当前进程安全设置 BLOCKTALK_TS_PASSWORD；不要写进提交的脚本。
.\gradlew.bat :core:integration -PprobeArgs='--switch-channel'
.\gradlew.bat :core:integration -PprobeArgs='--audio'
```

`--audio` 会打开真实麦克风，默认保持发送关闭。控制台 `status` 查看脱敏计数，
`talk 1` 至 `talk 5` 限时发送真实麦克风并自动关闭；`down`/`up` 模拟按下/松开，
`mute`、`deafen`、`join ID`、`quit` 控制联调。它不是日常按键模式；退出时释放资源。`--pair-smoke`
显式连接第二个独立 BlockTalk 身份，短暂发送双方的真实麦克风并验证解码；请只在
你可测试的服务器运行，不会发送测试音。默认无参数只验证连接，不打开麦克风。
可设置 `BLOCKTALK_CONFIG_DIR` 隔离测试身份，默认 `work/integration-private`。

## 常见问题

- **连不上**：核对 UDP 端口、SRV 和服务器是否可达；TSDNS 名称需改成真实地址。
- **密码错误/身份要求**：按错误提示处理；这些错误不会无限自动重试。
- **按 V 没声音**：查看面板中的实际原因；确认在世界内、窗口有焦点、不是输入框、
  设备可用、频道编码受支持并有发言权限，然后松开再按下。
- **设备失败**：确认系统麦克风权限和其他程序占用情况，选择明确设备并保存重试。
  默认设备在操作系统中的透明切换无法在所有驱动上可靠检测，隐私敏感场景应选定具体设备。
- **不支持的平台/原生库**：音频会禁用，设置仍可打开。首个已验证目标仅 Windows x86_64。
