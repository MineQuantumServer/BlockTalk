## 测试失败

最终自动化测试无未解决失败。开发期间发现并修复的 EAX 升级兼容、空属性合并、
开发类加载、重复退出以及原生候选问题均在 `TESTING.md` 中记录。
早期一个测试服务器因 stdin 关闭而被终止，命令退出 -1；后续交互式运行正常退出 0。
后续人工听音发现：BlockTalk 到官方客户端第一次 5 秒发送有严重杂音，恢复发送门
重试后用户报告正常。两次之间未修改编解码/增益配置，原因尚未定位；该质量问题
仍需复现调查，不能以重试正常宣称已修复。

## 已知限制

仅提供 Windows x86_64 原生音频；仅 TS3、20 ms Opus Voice/Music；无 TSDNS，
无 FEC/降噪/AGC/VAD/AEC、文字聊天和账号/文件/权限管理。系统默认设备的驱动
透明改路不能在所有系统上可靠检测。此版本应按 alpha 测试包使用。

## 真实阻塞

官方客户端测试端已参与并完成一次双向人工听音，但首次严重杂音尚未定位，
客户端版本和设备拓扑未确认；多平台、长期质量及设备故障验收仍未完成。
因此**只确认本次有限场景的双向听音，不能声明全部互通或正式发布验收完成**。

## 产物与复现

发行 JAR：`blocktalk-0.1.0-alpha.1.jar`；源码：`BlockTalk-source.zip`；哈希：
`SHA256SUMS.txt`。解压源码后设置 JDK 21 / `JAVA_HOME`，运行：

```powershell
.\gradlew.bat clean test build
.\gradlew.bat nativeSmoke :core:nativeTest
.\gradlew.bat runClient
```

硬件、协议环境变量及官方客户端联调方法见 `TESTING.md` 与 README。没有提交密码、
真实身份私钥或原始音频，没有发布 Release。
